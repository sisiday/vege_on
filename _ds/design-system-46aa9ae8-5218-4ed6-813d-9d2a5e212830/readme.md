# 야채온 (YACHAE ON) 디자인 시스템 v1.0

**부산 야채의 중심 야채온** — 반여농산물도매시장 중앙청과 112번 중도매인이 부산 식당 사장님께 새벽 경매 채소를 직거래로 납품하는 서비스.

- 슬로건(보조): 당일 경매의 신선함을 그대로 야채ON
- 타겟: 부산 식당 사장님(40\~60대 비중 높음, 바쁘고 모바일로 빠르게 훑어봄)
- 핵심 가치: ① 신선함(새벽 경매 → 당일 납품) ② 정직한 시세(중간 유통 없이 당일 시세 공유) ③ 든든한 동반자(품질검수, 100% 교환·환불, 사장님 응원단)
- 산출물 유형: 랜딩 페이지, 카드뉴스(1080×1350), 썸네일(16:9), 전단, 제안서, 배너

## CONTENT FUNDAMENTALS

- 언어: 모든 라벨·버튼·설명은 한국어. 영문은 브랜드 표기(VEGETABLE ON, 야채ON)에만.
- 말투: 사장님께 드리는 존댓말, 짧고 솔직하게. "\~해 드려요", "\~하세요", "\~했어요". 과장·최상급 표현 금지.
  - 예: "새벽에 직접 경매받은 물건을 그날 납품해 드려요." / "작황이 좋아 이번 주 저렴하게 들어왔어요." / "받아보시고 아니다 싶으면 100% 교환·환불해 드려요."
- 호칭: 고객은 "사장님". 회사는 "야채온" 또는 주어 생략. "저희"는 필요할 때만.
- 헤드라인: 15자 안팎, 핵심 단어 1개만 `--primary-500` 또는 `--secondary-carrot`으로 강조. 예: "부산 야채의 **중심**", "오늘의 **시세**".
- 본문: 한 문단 3줄 이내. 16px 미만 금지.
- 버튼: 동사로 끝냄 — "거래 문의하기", "시세표 보기", "상담 신청하기". 한 화면에 Primary 1개.
- 숫자: 가격·%·날짜는 크게. 천 단위 콤마(13,500원), 날짜 `2026.10.22`, 변동은 "▼ 1,200". 3초 안에 핵심이 보여야 한다.
- 오류 문구: 무엇을 하면 되는지 말한다 — "연락처를 끝까지 입력해 주세요".
- 이모지: 쓰지 않음. 유니코드는 가격 변동 화살표 ▼ ▲만 허용.
- 고정 문구: 상담문의 010-2820-0050 / 부산광역시 해운대구 수영강변대로 626, 반여농산물도매시장 중앙청과 112번 / 카드뉴스·전단·제안서 하단 슬로건 "당일 경매의 신선함을 그대로 야채ON"(caption, primary-500).

## VISUAL FOUNDATIONS

- 무드: 신선함 · 정직함 · 정겨움. 새벽 경매장의 초록 + 크림색 종이. 대기업 톤이 아니라 단골 상인의 명함처럼 친근하고 솔직하게. 휴머니즘 + 미니멀.
- 컬러: 크림 60 / 그린 30 / 오렌지·옐로 10 이하. 페이지 배경은 순백이 아니라 `--bg-base`(#F7F6ED), 카드만 흰색, 강조 섹션은 `--bg-inverse`(그린). 오렌지와 옐로는 각각 화면당 1\~2곳, 같은 요소에 겹쳐 쓰지 않음. 가격 하락·저렴 품목은 carrot, 빨강은 오류에만. 색 바탕 위 텍스트는 같은 계열의 가장 진한 색(검정 금지). 그린 위 본문은 bg-base, 보조는 primary-100.
- 금지: 네온·형광, 과한 그라디언트, 차가운 블루 메인, 어두운 배경, 무료 일러스트 혼용.
- 타입: Pretendard(한글) + Inter(영문·숫자). 헤드라인 700\~800 vs 본문 400 대비 확실히. 600은 H3와 버튼에만. 가격은 Inter 800 + tabular-nums.
- 스페이싱: 8px 시스템(4px는 미세 간격). 섹션 간격 64, 카드 패딩 24 이상. 여유롭게.
- 그리드: 데스크톱 max 1200 · 12col · 거터 24 · 여백 40 / 태블릿 8col · 20 · 32 / 모바일 4col · 16 · 20 / 카드뉴스 1080×1350 여백 80, 요소 간격 40 / 썸네일 16:9 여백 폭의 6%.
- 배경: 단색 크림 또는 단색 그린. 패턴·텍스처·그라디언트 없음. 이미지가 들어갈 때는 실사 사진(풀블리드 또는 radius 16 카드 안).
- 이미지: 실제 채소·경매장·배송 차량 실사. 따뜻한 자연광, 채도 살짝 높게. 흑백·차가운 톤 금지. 그레인 없음.
- 깊이: 그림자·글로우·3D 없음. 깊이는 크림 배경과 흰 카드의 대비 + 1px `--neutral-100` 테두리로만.
- 카드: 흰 바탕, 1px neutral-100, radius 16, 패딩 24, 그림자 없음. 강조형은 그린 바탕 + butter 뱃지 + 크림 버튼. 왼쪽 컬러 보더 카드 쓰지 않음.
- 테두리: 카드 1px, 컨트롤(버튼·입력) 1.5px.
- 라운드: 태그 6 / 버튼·입력 10 / 카드 16 / 뱃지 pill.
- hover: 한 단계 진한 색(primary-500 → 700). Secondary·Ghost는 primary-50 바탕. 불투명도 변화는 쓰지 않음.
- press: 별도 축소 없음 — hover 색 유지. disabled는 neutral-200 바탕 + neutral-400 텍스트, cursor not-allowed.
- focus: 그린 테두리 + `0 0 0 3px --primary-100` 링 (그림자가 아닌 포커스 표시로만 허용).
- 애니메이션: 최소. 색 전환 0.15s ease 정도, 부드러운 스크롤. 바운스·패럴랙스 없음.
- 투명도·블러: 쓰지 않음. 고정 헤더도 크림 단색 + 하단 1px 테두리.

## ICONOGRAPHY

- 스타일: 라인 아이콘, 선 두께 1.75\~2px, 색은 `--primary-500` 하나로 통일. 채움 아이콘·컬러 아이콘·3D 아이콘 금지.
- 세트: 원본에 아이콘 파일이 없어 **Lucide**(CDN `https://unpkg.com/lucide@0.460.0`, stroke 2)로 대체. 자주 쓰는 아이콘: carrot, leaf, truck, gavel, phone, receipt, badge-check, refresh-ccw, map-pin, handshake.
- 이모지: 사용 안 함. 유니코드는 ▼▲(가격 변동)만.
- 로고: `assets/logo.png` — 원형 엠블럼(새싹 + 해 + 밭) + "야채on" 워드마크. 로고가 놓일 수 없는 자리는 텍스트 로고 '야채온'(800, primary-500).
- 일러스트: 제공된 것 없음. 무료 일러스트 혼용 금지 — 실사 사진 자리(placeholder)를 두고 실제 사진을 받는다.

## 작업 지침 (항상)

1. 토큰(var(--…))으로만 스타일. 없는 색은 가장 가까운 토큰으로 대체.
2. 위계: bg-base 페이지 → 흰 카드 → bg-inverse 강조 섹션.
3. 결과물 끝에 사용한 토큰 목록을 한 줄로 덧붙인다.
